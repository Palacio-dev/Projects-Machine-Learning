# Project 03 - Dataset

This project uses **Camelyon17-WILDS**, a patch-level histopathology benchmark for tumor detection in H&E-stained lymph node sections. The dataset itself is **not included in this repository** (it is ~10.6 GB); the notebook downloads it automatically at runtime.

**Official page:** https://wilds.stanford.edu/datasets/#camelyon17

**Underlying challenge data:** [CAMELYON17 Grand Challenge](https://camelyon17.grand-challenge.org/)
